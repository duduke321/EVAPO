# EVAPO

**Evidence-Validated Adaptive Policy Optimization with On-Policy Self-Distillation for Audio-Language Models**

[English](README.md) | [中文](README_zh.md)

EVAPO 是一个面向音频语言模型的、以音频证据为基础的后训练框架。它将答案验证的强化学习与选择性在策略自蒸馏结合起来：每个有效样本都以经过验证的答案作为优化目标；同一个模型在特权上下文下产生的分布，仅在独立验证表明证据能够纠正当前错误时才用于自蒸馏。

## 动机

音频语言模型通常能够较好地识别声学内容，但仍然难以稳定地产生基于音频内容的可靠答案。后训练因此面临三个相互关联的问题：

- **RL 监督稀疏：** 纯 RL 提供了可信的答案目标，但稀疏奖励难以为困难的音频错误提供具体方向；
- **自蒸馏信号不可靠：** 标准 OPSD 提供了密集的指导，但特权上下文下的分布在学生生成的状态上可能不可靠，进而强化错误或无关行为；
- **特权信息泄露：** 特权文本或推理过程有助于改善模型在特权上下文下的判断，但也可能泄露答案，或让模型学到部署时不可用的捷径。

### 核心思路

一个有效的后训练方案需要同时满足两个目标：保留经过验证的答案作为最终训练目标，并且只在自蒸馏信号真正展现纠错价值时使用它。EVAPO 将特权上下文监督视为有针对性的纠错，而不是面向所有样本的统一模仿目标，在保留模型自身音频理解与决策能力的同时，为需要纠正的错误提供方向。

## 方法

EVAPO 将答案验证、证据门控、选择性 OPSD 和 SAPO 策略优化串联成一个训练流程：先判断候选证据能否纠正模型当前错误，再将特权上下文指导限制在需要纠正的 rollout 上。

该方法不引入独立的教师模型。学生分布与特权上下文分布由同一个模型在不同上下文下产生。

### 1. 证据验证与门控

候选证据通过四个互补视图进行验证，包括原始证据、去除答案信息后的证据视图、打乱证据顺序的控制视图，以及普通学生视图。只有同时满足以下条件时，证据才会进入特权自蒸馏分支：

1. 普通学生视图给出了错误答案；
2. 去除答案信息后的证据视图能够得到正确答案；
3. 打乱证据顺序的控制视图不能得到同一个答案；
4. 证据不包含标准答案、完整选项或其他形式的标签泄露。

该门控机制检验证据是否实际展现出纠错价值，而不是默认更长的推理文本一定有帮助。

### 2. 答案验证的 SAPO 目标

每个有效训练样本都以经过验证的答案为训练目标参与基于 SAPO 的策略优化。只有通过证据门控的样本才会向自蒸馏分支提供特权 `teacher_prompt` 上下文。

### 3. 选择性方向性 OPSD

对于通过门控的样本，特权上下文分布与普通学生分布之间的对数概率差提供方向性自蒸馏信号。干预仅作用于负向或回答错误的学生 rollout，并且只保留指向纠正方向的概率差。这样既能避免特权上下文覆盖已经正确的行为，也能降低自蒸馏信号噪声的影响。

## 方法针对的问题

EVAPO 针对音频后训练中的四类实际问题进行设计：

- **自蒸馏反馈噪声：** 证据必须证明特权上下文能够纠正真实的学生错误；
- **RL 监督稀疏：** 只在经过验证的救援样本上加入密集自蒸馏方向，同时保留答案奖励作为最终目标；
- **捷径与答案泄露：** 通过去答案信息和打乱证据的控制实验，排除仅依赖标签泄露的证据；
- **过度干预：** 方向性更新只处理负向或错误 rollout，使正确行为继续由答案目标约束。

该方法是一套训练方案，并未引入新的模型架构或独立教师模型。其核心在于将音频驱动的证据验证、选择性错误救援、方向性 OPSD 与答案验证的 SAPO 策略优化组合成一个兼容部署的训练流程。
